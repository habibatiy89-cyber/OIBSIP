# Task 1 · Landing Page

##  Project Overview
This is a visually polished, modern, and fully responsive static landing page built for **TaskFlow** — a smart project and team workspace. 

---

##  Tech Stack
- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3**: Modern layouts using Flexbox and CSS Grid (no JavaScript required).

---

##  Features Checklist
- [x] **Sticky Navigation Bar**: Fixed at the top with brand logo, smooth scroll navigation links, and a call-to-action button.
- [x] **Hero Section**: Engaging headline, subheadline, status pill badge, dual CTA buttons, trust indicators, and a Kanban board preview card.
- [x] **Features Section**: 6-card responsive CSS grid highlighting core platform capabilities with hover effects.
- [x] **About & Stats Section**: Brand story paired with key metrics (99.98% uptime, 45 min saved daily, 120k+ tasks shipped).
- [x] **Testimonials Section**: 3 customer review cards with 5-star ratings and author avatars.
- [x] **Call-to-Action (CTA) Banner**: High-conversion banner before the footer.
- [x] **Footer**: Comprehensive 4-column footer with contact details, social links, and copyright notice.
- [x] **Consistent Colour Palette**: Cohesive design system built with CSS custom properties (`:root`).
- [x] **Fully Responsive**: Media queries ensuring seamless viewing on mobile, tablet, and desktop devices.
- [x] **No Element Overlap**: Global `box-sizing: border-box;` reset with intentional margin and padding.
- [x] **Clean Typography**: Readable hierarchy using Google Fonts (*Inter*).
