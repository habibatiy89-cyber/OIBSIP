# OIBSIP - Task 2 · Personal Portfolio

### Project Overview
A personalized, visually engaging, and responsive developer portfolio website built as part of the **Oasis Infobyte (OIBSIP) Web Development Internship**. This digital résumé highlights technical competencies, real-world projects, educational background, and contact methods.

###  Tech Stack
- **HTML5**: Semantic document layout and accessible elements.
- **CSS3**: Custom design system, Flexbox, Grid, smooth animations, and dark/light mode themes.
- **JavaScript (Vanilla)**: Mobile navigation toggle, smooth scroll highlighting, dark mode toggle with localStorage persistence, and interactive contact form feedback.

###  Feature Checklist
- [x] **Profile / Hero Section**: Name, professional title, personalized greeting, avatar placeholder, and resume CTA.
- [x] **About Me Section**:  describe coding journey, core principles, and personal hobbies.
- [x] **Skills Section**: Visual categorized grid of frontend, styling, and tool technologies.
- [x] **Projects Section**: Featured project cards showcasing titles, descriptions, live demo links, and GitHub links.
- [x] **Contact Section**: Functional contact form with live validation and social connectivity links (GitHub, LinkedIn, Twitter, Email).
- [x] **Smooth Scroll Navigation**: Floating sticky navbar with section active state indicators.
- [x] **Theme Switcher**: Dark and light mode toggle with state saved to browser storage.
- [x] **Responsive Layout**: Designed mobile-first, ensuring zero element overlap on any screen width.
