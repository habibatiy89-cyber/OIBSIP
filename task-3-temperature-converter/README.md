# OIBSIP - Task 3 · Temperature Converter Website

###  Project Overview
An interactive, warm, and beginner-friendly web application that converts temperatures seamlessly across **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)** with real-time input validation, edge case alerts for physical absolute zero, and  temperature sensations.

### Design Palette (No Black or Purple)
Designed with a natural, welcoming temperature theme:
- **Ocean Teal & Sky Blue** (`#0284c7`, `#0ea5e9`, `#e0f2fe`) — Representing cool and refreshing temperatures.
- **Warm Amber & Coral** (`#ea580c`, `#f97316`, `#ffedd5`) — Representing warmth, heat, and active states.
- **Soft Cream / Slate** (`#f8fafc`, `#ffffff`, `#334155`) — Clean, readable surfaces with zero pure black or AI-like dark-purple tones.

###  Features Checklist
- [x] **Numeric Input Field**: Validates numbers with error messages on invalid input.
- [x] **Unit Selector**: Intuitive radio pill buttons allowing seamless switching between Celsius, Fahrenheit, and Kelvin.
- [x] **Multi-Unit Simultaneous Output**: Displays converted values across all three units simultaneously in real-time.
- [x] **Convert & Reset Actions**: Dedicated Convert button to trigger calculation, plus a Clear button.
- [x] **Absolute Zero Edge Case Handling**: Highlights physical boundaries below −273.15°C, −459.67°F, or 0 K with a friendly science note.
- [x] **Temperature Sensation Indicator**: Displays relatable feeling badges (e.g., ❄️ Freezing,  Room Temp,  Hot,  Boiling).
- [x] **Quick Presets**: 1-click buttons for common temperatures (Freezing, Room Temp, Human Body, Water Boiling).
- [x] **Formula Reference**: Simple mathematical explanations of each temperature formula.
- [x] **Clean, Centered Layout**: Beautifully balanced, fully responsive card layout for mobile, tablet, and desktop.
